# 🖥 시뮬레이터 사용 방법

1. **웨이퍼 삽입**
   - LoadPort 1 또는 2에 웨이퍼를 삽입합니다.
   - 두 LoadPort는 **동시 Processing 가능**
   - 참고: [LoadPort.md](LoadPort.md)

2. **Carrier ID 설정**
   - SwingSecsSimulator에서 **Carrier ID**를 설정합니다.  
   - SECS/GEM 메시지: **S3F17**

3. **PJ ID 설정**
   - SwingSecsSimulator에서 **PJ ID**를 설정합니다.  
   - SECS/GEM 메시지: **S16F11**

4. **CJ ID 설정 및 시뮬레이터 동작**
   - SwingSecsSimulator에서 **CJ ID**를 설정하면 시뮬레이터가 자동으로 동작합니다.  
   - SECS/GEM 메시지: **S14F9**
